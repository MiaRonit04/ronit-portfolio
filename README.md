# Ronit Mia — Personal Portfolio

A responsive, dark, animated portfolio built with React + Vite. It features experience, education, skills, selected projects, contact links, and a downloadable resume.

## Run locally

1. Install Node.js (LTS) from https://nodejs.org/ if it is not installed.
2. Open Terminal in this folder.
3. Run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL Vite prints (usually http://localhost:5173).

## Free deployment on Vercel

1. Push this folder to a new GitHub repository.
2. Sign in at https://vercel.com/ and import that repository.
3. Use build command `npm run build` and output directory `dist` (Vercel usually detects Vite automatically).
4. Click Deploy. Vercel provides a free `*.vercel.app` URL.

You can also deploy on Netlify using `npm run build` and `dist` as the publish directory.
